# First Vertical Slice — Production Contract

**Goal:** A coherent, repeatable, 10–15 minute play experience demonstrating the core loop.

## Content cap
- 1 tavern interior and 1 compact forest
- 1 controllable player character
- 5 ingredients, 3 recipes
- 2 supernatural guest archetypes
- 1 meaningful upgrade, preferably expanded satchel
- Gathering, inventory, cooking, voluntary open/close, ordering, serving, coins, save/load
- Basic feedback, ambience and coherent art

## Milestones
**M0 Foundation:** New Godot project, exact engine version pinned, docs, architecture, asset provenance and validation scripts.
**M1 Visual benchmark:** Four-direction character, detailed forest, tavern interior, collision, camera, transitions, coherent pixel scale.
**M2 Gathering:** Five ingredients, interactables, inventory transaction tests and UI.
**M3 Cooking:** Three recipes, ingredient consumption, short tactile interaction, feedback.
**M4 Tavern:** Open/close control, two guest types, orders, serving, coins, one upgrade that improves exploration.
**M5 Integration:** Save/load, repeatable complete loop, playtest and bug fixes.

## Exit criteria
Actually run in Godot; no missing scene/resource references; no item duplication/negative inventory; meaningful upgrade; save/reload preserves progress; loop completes without developer commands; clear art-quality review. A script existing is not proof of a working feature.

## Deferred
Farming system, fishing system, combat, multiple regions, complex leveling trees, staff automation, long story arcs, procedural world.
